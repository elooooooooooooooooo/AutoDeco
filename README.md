# Auto Deco (Geode)
1. Neues GitHub-Repo erstellen, alle Dateien hochladen (inkl. .github-Ordner).
2. Tab "Actions" -> "Build Mod" -> "Run workflow".
3. Nach dem Build unter Artifacts "Build Output" herunterladen -> enthält user.auto-deco.geode.
4. .geode in den Geode-Mods-Ordner legen.
Im Editor: Objekte auswählen -> Button "Auto Deco" (oben rechts). Einstellungen: Geode -> Mods -> Auto Deco.
